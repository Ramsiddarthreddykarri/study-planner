# study-planner
A simple Python-based study planner to organize subjects, topics, difficulty levels, and track study progress.

## Features

* Add subjects
* Set exam dates
* Add topics under each subject
* Set difficulty levels for topics
* Generate a study plan
* Mark topics as completed
* Track progress for each subject

## Technologies Used

* Python
* Lists
* Dictionaries
* Loops
* Conditional statements

## How It Works

The program stores subjects and their topics using lists and dictionaries.

Each topic has a difficulty level and a completion status. The study plan gives priority to harder unfinished topics.

## How to Run

Run the Python file using Python 3.
